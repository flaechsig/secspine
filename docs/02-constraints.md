# Randbedingungen

- **Python 3.9 oder neuer** für das Prüfwerkzeug; dieses nutzt ausschließlich die
  Standardbibliothek.
- **Git** als Grundlage der Arbeitsweise (Branch je Testrunde, Historie als Nachweis).
- **Docker**, um fehlende Scanner als Container zu fahren.
- Dirigierte Scanner: Semgrep, Trivy, gitleaks, OWASP ZAP, Nuclei, nmap.
- Getestet werden ausschließlich **eigene oder ausdrücklich autorisierte** Ziele.
